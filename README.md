# claude-usage-mods

클로드 코드 사용량을 늘 보이게 하고, 쌓인 대화를 정리하는 mod 3개입니다.
영상 「AI 쉽게 알려드림」에서 직접 쓰는 모습을 보여 드린 그 코드입니다.

영상: (업로드 후 링크)

## 무엇을 하나요

| mod | 하는 일 | 지우는 기능 |
|---|---|---|
| `usage-status` | 프롬프트 바로 위에 대화 크기와 5시간·주간 한도, 리셋 시각을 한 줄로 띄웁니다 | 없음 |
| `resume-delete` | `/resume`(또는 `/sessions`)을 [재개]·[삭제] 버튼이 있는 창으로 엽니다 | 있음 (두 번 눌러야 확정) |
| `clear-purge` | `/clear`로 떠난 대화의 기록을 바로 지웁니다. `/new`·`/reset`으로 연 대화는 남깁니다 | 있음 (바로 지움) |

`usage-status`가 띄우는 줄은 이렇게 생겼습니다.

```
컨텍스트 5% 51.2k/1.0M │ 5시간 4% · (14:10 리셋) │ 주간 44% · (10/29(목) 02:00 리셋)
```

- **컨텍스트**: 지금 대화가 얼마나 커졌는지입니다. 대화가 길수록 질문 하나에 드는 사용량도 커집니다.
- **5시간·주간**: 구독 한도를 얼마나 썼는지와, 언제 다시 채워지는지입니다.

처음 써 본다면 `usage-status` 하나만 설치해도 충분합니다. 나머지 둘은 지난 대화를 지우는 기능이라, 아래 [주의](#주의)를 먼저 읽어 주세요.

## 알아 두면 좋은 것: /clear는 지우기가 아닙니다

클로드 코드의 `/clear`는 이름과 달리 **새 대화를 여는 명령**입니다. `/new`·`/reset`도 같은 명령입니다.
지난 대화는 그대로 남아 있어서 `/resume`으로 다시 열 수 있습니다. `/clear 이름`처럼 치면 그 대화에 이름이 붙습니다.

`clear-purge`는 이 기본 동작을 바꾸는 **제 개인 설정**입니다. 공식 기능이 아닙니다.
설치하면 이렇게 됩니다.

| 입력 | 클로드 코드 기본 | `clear-purge` 설치 후 |
|---|---|---|
| `/clear` | 새 대화, 지난 대화 남음 | 새 대화, **지난 대화 지움** |
| `/new`, `/reset` | 새 대화, 지난 대화 남음 | 새 대화, 지난 대화 남음 |

## 설치

클로드 코드 v2.1.287 이상이 필요합니다. 터미널에서 `claude --version`으로 확인할 수 있습니다.

1. 이 저장소를 내려받습니다. 위쪽 초록색 **Code** 버튼 → **Download ZIP**으로 받아 압축을 풀어도 됩니다.
2. 터미널에서 내려받은 폴더로 이동한 뒤, 쓰고 싶은 mod 폴더만 `~/.claude/mods/`로 복사합니다.

   ```
   mkdir -p ~/.claude/mods
   cp -R plugins/usage-status ~/.claude/mods/
   ```

   셋 다 쓰려면 `cp -R plugins/* ~/.claude/mods/`로 한 번에 복사합니다.

3. `~/.claude/settings.json`을 열어 `env` 안에 아래 줄을 넣습니다. `env`가 없으면 통째로 추가합니다.

   ```json
   "env": {
     "CLAUDE_CODE_PLUGIN_DIRS": "~/.claude/mods"
   }
   ```

   이미 `CLAUDE_CODE_PLUGIN_DIRS`가 있다면 새로 넣지 말고, 2번에서 그 경로로 복사하세요.

4. 클로드 코드를 다시 켭니다. `/plugin`을 열었을 때 mod 이름이 보이면 켜진 것입니다.
   `usage-status`는 첫 질문에 답을 받은 뒤부터 한도 숫자가 나옵니다.

## 끄기·업데이트

- **끄기:** `~/.claude/mods/`에서 그 mod 폴더를 지우고 클로드 코드를 다시 켭니다.
- **업데이트:** 새로 내려받은 폴더로 같은 자리를 덮어쓰고 다시 켭니다.

## 주의

- **`resume-delete`와 `clear-purge`로 지운 대화는 되돌릴 수 없습니다.** `/resume` 목록에서도 사라지고, 그 대화에서 고친 파일의 편집 이력도 함께 지워집니다. 남겨야 할 대화가 있다면 설치 전에 따로 보관해 두세요.
- 지난 대화를 남기는 기본 동작이 좋다면 `clear-purge`는 설치하지 마세요. 새 대화는 그냥 `/clear`나 `/new`로 열면 됩니다.
- `clear-purge`는 클로드 코드가 남기는 입력 기록 파일(`~/.claude/history.jsonl`)을 읽어 `/clear`와 `/new`·`/reset`을 구분합니다. 이 파일 형식은 공식으로 보장된 것이 아니라서, 업데이트 뒤 구분하지 못하면 **지우지 않고 남기는 쪽으로** 동작합니다.
- `resume-delete`는 대화 목록을 읽을 때 `python3`을 씁니다. 맥에서 `python3`이 없다고 나오면 Xcode 명령어 도구를 설치하세요(`xcode-select --install`).
- mod는 내 컴퓨터에서 내 권한으로 실행되는 코드입니다. 설치 전에 `plugins/` 안의 코드를 열어 보거나, `claude plugin validate ./plugins/<이름>`으로 확인할 수 있습니다.
- 5시간·주간 한도는 Pro·Max·Ultra 구독에서만 표시됩니다. 2026년 10월 30일부터 Ultra(구 Max 20x)는 인증된 계정에 5시간 한도가 없어서, 이때는 5시간 칸 없이 컨텍스트와 주간만 나옵니다([Ultra 요금제 안내](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan)).
